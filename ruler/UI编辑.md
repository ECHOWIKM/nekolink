你现在已经拿到了 NekoLink 的完整源码。

这是一个 Windows 桌面软件：

NekoLink
iPhone → Windows → Telegram / 钉钉 / ntfy / GoNotify / 邮件

请先阅读整个项目，然后按照下面的要求进行 UI 重构。

============================================================
【非常重要：不要重写业务逻辑】
============================================================

这是 UI 重构，不是业务重构。

绝对不要修改：

ancs_bridge.py 中的：

- BLE 连接
- ANCS 协议
- 通知接收
- 通知解析
- Telegram
- 钉钉
- ntfy
- GoNotify
- Email
- 模板变量替换
- 配置读取
- 配置保存
- 验证码识别
- 去重
- 历史数据逻辑

除非为了让 UI 获取数据而增加极少量 UI helper。

不要改变 config.json 的字段结构。

不要删除已有功能。

不要删除已有事件处理函数。

不要改变已有业务 API。
